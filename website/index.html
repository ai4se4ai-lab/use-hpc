A FEW PRACTICAL DETAILS

Before you start.

Is use-hpc tied to Claude?

No. All five installation targets receive the same SKILL.md, references, scripts and templates. The pipeline uses ordinary Python, Bash and Slurm commands. Your chosen coding agent handles the conversation and edits.

Does installation run experiments?

No. Installation adds the skill to your agent. The template is a starting point: you and your agent must configure cluster resources and replace example experiment commands with your project's real entry points. GPU submissions require your approval.

Will it work on my Slurm cluster?

The defaults follow Digital Research Alliance of Canada practices. Adapt cluster.env, module names, storage paths, GPU requests, and package installation to your site. Read the cluster documentation with your agent before submitting.

Can I still use the Claude Code plugin?

Yes. The existing marketplace installation is preserved. Choose either the plugin or the skill installer for Claude Code to avoid duplicate listings. Other agents use the portable skill directly.
